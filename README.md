 SAM V1 - The Origin of DedSec

"All systems online, sir. How may I assist?"

SAM (System Automation Module) is a Python-based voice assistant built from scratch. This is V1 — the origin of what later evolved into **DedSec**, an agentic AI cybersecurity system.

---

## Features

- Voice recognition & text-to-speech
- Web search via DuckDuckGo
- YouTube playback
- System control (shutdown, restart, lock)
- Battery & system status
- Volume control (up, down, mute)
- Screenshot capture
- Jokes, time & date

---

## Project Structure
```
SAM-V1/
├── sam1.py              # Standalone version
├── modules/
│   ├── config.py        # TTS engine & queue setup
│   ├── voice.py         # Speech input & output
│   ├── apps.py          # App launcher
│   ├── system.py        # System commands
│   ├── web.py           # Web & YouTube search
│   └── fun.py           # Jokes, time, screenshots
```
