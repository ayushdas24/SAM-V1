SAM V1 - The Origin of DedSec
"All systems online, sir. How may I assist?"

SAM (System Automation Module) is a hybrid voice assistant that combines local system automation with a Generative AI Brain. This is V1 — the foundation of an autonomous AI ecosystem.

🧠 The Generative Core
Unlike standard assistants, SAM-V1 is powered by the Gemini 1.5 Flash model. This allows for:

Contextual Conversations: SAM doesn't just follow commands; he understands intent.

DedSec Persona: Integrated system instructions to maintain a witty, loyal, and "hacker-style" personality.

Dynamic Problem Solving: If a local command isn't found, the Generative Brain takes over to provide answers.

🛠️ Features
Neural Link (Generative AI): Real-time thinking and response generation.

Voice Interface: Speech-to-text recognition and threaded text-to-speech (no lag!).

OS Integration: Lock system, volume control, and screenshot capture.

System Awareness: Real-time battery status and charging reports.

Web Ops: DuckDuckGo search and direct YouTube playback.

Utility: App launching (Notepad, Calculator, etc.), jokes, time, and date.

🛠️ Setup
Clone the repo.

Install dependencies: pip install pyttsx3 speechrecognition google-generativeai psutil pyautogui.

Add your Gemini API Key in main.py.

Run: python main.py.
